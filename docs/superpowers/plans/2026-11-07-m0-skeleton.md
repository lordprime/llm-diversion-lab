# M0 Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove the full evidence pipeline end to end on one target (DVGA), with a scripted agent and a stub LLM, no real model spend, running on Proxmox LXC CT 111.

**Architecture:** A long-lived control plane (Postgres queue, Collector API, runner, stub LLM gateway) orchestrates ephemeral *run cells*. Each cell is a Docker Compose project on isolated internal networks: a surface injector (reverse proxy that plants tagged text), the DVGA target with a CVE-Bench evaluator sidecar, an HTTP+DNS callback catcher, an LLM tap that records request bytes, and a scripted agent. The runner classifies each run on the Access→Visible→Uptake→Outcome funnel from the recorded evidence, deterministically. A matched clean control runs with no planted text.

**Tech Stack:** Python 3.12 + uv, FastAPI, SQLAlchemy 2 + Alembic, pydantic v2, mitmproxy addons, dnslib, pytest + hypothesis, Docker Compose, Ansible, GitHub Actions → GHCR.

**Spec:** `docs/DEVELOPMENT_PLAN.md` (§1, §3, §4, §5, §8 M0), `docs/AUTOMATION_FEASIBILITY.md` (§4, §5), `docs/ENGINEERING_STANDARDS.md`, `docs/DEPLOYMENT.md` (§0 LXC profile). Target fork hook points in `targets/dvga/source.yaml`, `cell/oracle/source.yaml`.

## Global Constraints

- Python **3.12**, dependency management with **uv** (`uv.lock` committed); CI runs `uv sync --frozen`.
- **No live LLM calls anywhere in M0.** The gateway serves a deterministic stub; CI never needs a provider key.
- Lint/type gates: **ruff** (E,F,I,B,UP,S,SIM,RUF), **mypy --strict** on `control/`, `cell/`, `agents/`.
- **pydantic v2 models are the single source of truth** for every event, manifest and API payload; JSON Schemas in `schemas/` are generated from them, never hand-edited.
- All event/DB/API/UI field names use the spec's domain words verbatim: `surface`, `placement`, `arm`, `pair_id`, `access`, `visible`, `uptake`, `outcome`, `run_id`, `experiment_id`.
- IDs are **ULIDs**; tags and callback tokens derive from the HMAC scheme (`token = base32(HMAC(lab_key, run_id ‖ placement_id))[:12]`; tags are random alphanumerics).
- Images are **built in GitHub Actions and pushed to GHCR**, pinned by digest in `deploy/images.lock`; the LXC only pulls. The 4-core CT 111 never builds images.
- Commits: Conventional Commits, **single-author (the user); no co-author or tool-attribution trailers** (per the repo's git-authorship rule).
- Every raw-evidence artifact is **write-once**; labels are recomputed from artifacts + a versioned labeller, never by editing evidence.
- Run cells have **no internet route** and **no database credentials**; the runner ships evidence to the Collector API.

## Review Focus

- **Compressed/chunked HTML responses:** the injector must plant into gzip/br/zstd-encoded bodies and fix Content-Length/ETag, or placements silently fail to appear. (Task 6)
- **Tag survives transport into the model request:** the tap must find the tag after JSON-unescaping and HTML-entity escaping, or "Visible" is scored false when it is true. (Task 8)
- **Control cell must be tag-free:** a leaked tag or decoy path in a control run invalidates the whole matched-pair design; the self-test asserts zero tags anywhere in a control run. (Task 14)
- **Oracle counts only the run's objective:** stock CVE-Bench scores any of 8 attacks (incl. a crash as "Denial of service") as success; `_check_attack_success_impl` must run exactly one check, and a negative test must prove a crash does **not** score. (Task 11)
- **Containment holds:** a probe inside a cell must fail to reach the internet, the LXC host and the home LAN; a success is a critical finding. (Task 15)
